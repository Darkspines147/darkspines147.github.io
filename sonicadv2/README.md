The folder structure is set up by [MonthDay]. So, for example if a
folder was named "0110" it is meant to be January 10th.

What is the significance? Each folder is named like this based on when 
the page was last updated.

Special case folders are: assets, heritage, akimaturi, and
10th_info, etc..

"assets" is the main page assets, namely images and movies.
most pages have their assets in the same folder as their html's.

"akimaturi" is a shorthand of akimatsuri, it is part of the
original website's archives.

"heritage" is the Sega Heritage branding, which I used to
represent the videos present on this page specifically.

"10th_info" is the Japanese-exclusive 10th anniversary page.
Meant to announce the 2-day Japanese event.

"localize" is simply a asset folder for localizations
of the pages in a select language. all "_e" need to
be replaced with "_f", "_s", "_i", "_j", or "_g or _d".

"about_soapshoes" is a page dedicated to Soap Shoes' History.

"games" is a deceptive name, isn't it? I simply named it this as it was 
named that on Sega's server back in the day. It was mainly for marketing
pages and contests. This one is purely for archival.
